فهرست صفحات زیر (با شناسه، عنوان و کلیدواژه اصلی) متعلق به یک سایت است:
{pages_list}

جفت‌صفحاتی که از نظر موضوعی مرتبط‌اند و منطقی است به هم لینک داخلی بدهند را پیشنهاد بده، همراه با متن انکر پیشنهادی و دلیل کوتاه.

قوانین:
- فقط از شناسه‌های (id) داده‌شده در فهرست بالا استفاده کن، هیچ id دیگری نساز.
- یک صفحه نباید به خودش لینک بدهد.
- حداکثر ۱۰ پیشنهاد بده؛ اگر ارتباط معناداری بین صفحات نیست، آرایه‌ی خالی برگردان.

خروجی را فقط به‌صورت این JSON بازگردان، بدون هیچ متن اضافه:
{{"suggestions": [{{"source_id": 1, "destination_id": 2, "suggested_anchor": "...", "reason": "..."}}]}}
